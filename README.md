# 태양광 입지 분석기

태양광 발전소 부지의 입지·인허가·부담금을 분석하는 정적 웹 도구입니다.

## GitHub Pages로 배포하는 방법

1. 이 폴더(`index.html`, `README.md`)를 새 GitHub 저장소에 업로드합니다.
2. 저장소 **Settings > Pages** 메뉴로 이동합니다.
3. **Branch**를 `main`(또는 `master`), 폴더를 `/ (root)`로 설정 후 저장합니다.
4. 몇 분 후 아래 형태의 주소로 접속할 수 있습니다.

```
https://[GitHub 사용자명].github.io/[저장소명]/
```

## 참고
- 별도의 서버나 빌드 과정 없이 순수 HTML/CSS/JS로 동작합니다.
- 파일명은 반드시 `index.html`이어야 GitHub Pages 루트 주소에서 바로 열립니다.
